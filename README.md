# しぐれとのアドオン置き場

マイクラ統合版の自作アドオン配布サイト（GitHub Pages）。

## 新しいアドオンを追加するとき

1. `.mcaddon` ファイルをそのまま追加する
2. サムネイルとスクリーンショットを `アドオン名_画像名.jpg` の名前で追加する
3. `addons.json` の `"addons"` に1件追加する（ブーメランの書き方をコピーして書き換える）
   - `number` が大きいものほど一覧の上に出ます
   - `downloads` の `file` は手順1で入れたファイル名に合わせる
4. 保存（コミット）すると、1〜2分でサイトに反映されます

GitHub の画面なら「Add file → Upload files」でファイルを追加し、
`addons.json` は鉛筆マークから直接編集できます。

## アドオンごとのリンク

`https://<ユーザー名>.github.io/#boomerang` のように、`#` の後ろに `id` を付けると、
そのアドオンの位置から開きます。YouTube の概要欄にはこの形で貼ると便利です。
